# EduApp — новая главная (kk / ru)

Статическая главная страница: HTML, CSS и JS без фреймворков и зависимостей. Сразу два языка на отдельных URL: так поисковики видят текст без исполнения JavaScript.

```
src/template.html     главная страница (один шаблон на оба языка)
src/tests.html        страница «Тесттер» — каталог сынақ тестов
src/partials/         общие части страниц: sprite (иконки), header (шапка + меню), footer, tail (кнопки, окно теста, скрипты)
src/i18n/kk.json      тексты на казахском
src/i18n/ru.json      тексты на русском
src/tests-data.json   каталог тестов (СЛУЧАЙНЫЕ демо-данные)
tools/scrape-tests.mjs  обновление каталога тестов с eduapp.example.com
assets/               стили, скрипты, картинки (в сборке → /lp/)
  fx.css, fx.js       модуль эффектов: галактический фон, 3D-наклон, spotlight, звёзды
  site.css, site.js   стили и логика сайта (переключение языка, меню «Тесттер», кнопка «Жоғарыға»)
  trial.css, trial.js окно «Тегін сынақ тест»: формат → предмет → тест → результат
  tests.css, tests.js страница «Тесттер»: сыныптар, бағыттар, фильтры, разделы, тесты
  tests/              иконки разделов тестов
build.mjs             сборщик (кладёт словари в dist/lp/i18n.js, каталог — в dist/lp/tests-data.js)
dist/                 готовый сайт: index.html (kk), ru/index.html (ru), tests/, ru/tests/, lp/
ПЛАН-ПЕРЕЗАПУСКА.md   план, SEO-матрица, UX-флоу
```

## Карта «Оқу орбитасы» и кнопка «Жоғарыға»: настройка цветов и иконок

**Карта** — блок `.orbit` в hero (`src/template.html`), стили — раздел «Оқу орбитасы» в `assets/site.css`.

- **Цвет узла** задаётся классом на кнопке `.ob-node`: `ob-blue`, `ob-green`, `ob-violet`, `ob-orange`, `ob-gold`. Новый цвет — новый класс с четырьмя переменными:

  ```css
  .ob-pink{--c:#EC4899;--hi:#FCE7F3;--lo:#831843;--gl:rgba(236,72,153,.7)}
  /* --c основной цвет шара, --hi блик, --lo тень, --gl свечение */
  ```
- **Иконка** — `<use href="#i-target"/>` внутри `.ob-orb` и `.ob-plate`. Доступные иконки — `<symbol id="i-…">` в `src/partials/sprite.html`; новую иконку добавьте туда же.
- **Подписи и подсказки** — ключи `map.*` (плашки, «Қадам», описание цели) и `game.s1…s5.*` (тексты подсказок) в `src/i18n/*.json`. Прогресс шага: `--p:50%` в `.ob-tip-bar i` и текст «3 / 6».
- **Позиция узла:** `style="--x:63.5%;--y:42%"` — доля ширины и высоты карты. Линия пути — атрибут `d` у `#ob-route` в той же системе координат 520×500.
- **Неоновые орбиты и путь:** градиенты `#ob-neon`, `#ob-neon2`, `#ob-route-g` внутри SVG карты.
- **Звёзды:** `<i style="--x;--y;--s;--d">` в `.ob-stars` (позиция, размер, задержка мерцания).
- **Производительность:**
  - пока страницу прокручивают, на `<html>` стоит класс `is-scrolling`: анимации карты на паузе, размытие стекла выключено;
  - вне экрана анимации тоже на паузе (`.is-off`).

  Не убирайте эти правила — без них прокрутка снова начнёт тормозить на слабых ноутбуках.

**Кнопка «Жоғарыға»** — разметка в `src/partials/tail.html`, стили — «Кнопка «Жоғарыға / Наверх»» в `assets/site.css`.

- Цвета неоновой рамки: `--tt-a`, `--tt-b`, `--tt-c` в `.totop`. Цвета кольца прогресса: `<linearGradient id="totop-g">` в разметке.
- Порог появления (300 px) — `var show = y > 300` в `assets/site.js`. Прогресс 0–100% там же (`strokeDashoffset`).
- Иконка — `#i-arrow`, повёрнута на −90°. Другую стрелку можно взять из спрайта и убрать `rotate(-90deg)` в `.totop-arrow`.

## Страница «Тесттер» (/tests/, /ru/tests/)

Раздел «Тесттер» перенесён с eduapp.example.com:

- **В шапке** меню «Тесттер» → «Қазақ сыныптарына / Орыс сыныптарына» → ҰБТ, НЗМ, БИЛ, РФММ, Сыныптар бойынша, как на старом сайте. Ссылки вида `/tests/#kk/nis` сразу открывают нужный бағыт. На телефоне то же самое есть в мобильном меню.
- **На странице:**
  - переключатель «Қазақ сыныптары / Орыс сыныптары»;
  - вкладки бағыттов с числом тестов;
  - фильтр «Пән», для «Сыныптар бойынша» ещё фильтр «Сынып»;
  - поиск по названию;
  - карточки разделов с иконками → тесты раздела: время, класс, предметы, цена;
  - кнопка «Бастау».
- **В демо-каталоге 208 тестов в 34 разделах (случайные данные, `node tools/generate-demo-catalog.mjs`).** Пустые разделы и тест-заглушка «1» скрыты. Готовый HTML каталога собирается при сборке, поэтому его видят поисковики.
- **«Бастау»** ведёт на страницу теста на eduapp.example.com (`/Test/Overview/{id}`): тесты, оплата и результаты пока работают там. Когда тесты появятся на платформе eduapp.example.com, поменяйте одну функцию `TEST_URL` в начале `assets/tests.js`.
- **Обновить каталог,** когда на старом сайте появятся новые тесты:

  ```bash
  node tools/scrape-tests.mjs   # ~5 минут: собирает разделы, тесты, предметы и иконки
  node build.mjs
  ```

## Что изменилось (октябрь 2026)

- **Прокрутка больше не «застревает».** Тормозили постоянные анимации на всей странице сразу:
  - движущиеся звёздные фоны на 9 тёмных панелях (слой был на 80% больше панели);
  - размытие (`backdrop-filter`) под шапкой — оно пересчитывалось на каждом кадре;
  - звёзды на canvas.

  Сейчас фоны статичные, шапка без размытия, звёзды рисуются не чаще 30 раз в секунду и замирают во время прокрутки. Анимации блоков за пределами экрана стоят на паузе (класс `.is-off`). В тесте прокрутки длинные кадры сократились в 5 раз. Добавлена кнопка «Жоғарыға / Наверх», клик по логотипу плавно поднимает наверх.
- **ҚАЗ | РУС на одной странице.** Язык меняется сразу, без перезагрузки:
  - сборщик помечает каждый текст атрибутом `data-i18n`;
  - `site.js` подставляет текст из словаря;
  - адрес меняется на `/` или `/ru/`, кнопка «Назад» работает.

  Отдельные URL для поисковиков остались. Если открыть файл с диска, язык тоже переключается (адрес при этом не меняется).
- **«Тегін сынақ тест тапсыру»** открывает отдельную страницу внутри сайта (адрес `#sinaq-test`, ссылка `eduapp.example.com/#sinaq-test` открывает тест сразу):
  - Онлайн → предмет (математика, английский, логика, казахский) → 8 вопросов → результат по темам → «Тестті жалғастыру — тіркелу» (`https://eduapp.example.com/register`);
  - Оффлайн → «Instagram-ға жазу» (`https://ig.me/m/eduapp_demo`, личные сообщения @eduapp_demo). Ссылка задана в `OFFLINE_URL` в начале `assets/trial.js` — её легко заменить, например, на WhatsApp.

  Тексты окна — ключи `trial.*` в `src/i18n/*.json`, вопросы — `BANK` в `assets/trial.js`. Любая ссылка с атрибутом `data-trial` открывает тест. Без JavaScript такая ссылка ведёт на регистрацию.

## Сборка

```bash
node build.mjs
```

Нужен Node 18+. Сборщик остановится с ошибкой, если в одном из языков не хватает ключа из шаблона.
Правки текстов делайте в `src/i18n/*.json`, правки разметки — в `src/template.html`, затем пересоберите.

Для локального просмотра откройте `dist/index.html` двойным кликом или запустите `serve.bat` (сервер `serve.py` на http://localhost:8000 отдаёт файлы с `Cache-Control: no-cache`, поэтому после пересборки достаточно обычного F5).

## Запуск на eduapp.example.com (рядом с текущим Vue-приложением)

`/` и `/ru/` отдаются готовым HTML из `dist/`, всё остальное по-прежнему обслуживает SPA:

```nginx
# /var/www/eduapp/spa      — текущая сборка Vue (index.html, assets/)
# /var/www/eduapp/landing  — содержимое dist/ (index.html, ru/, lp/)
location = /    { root /var/www/eduapp/landing; try_files /index.html =404; }
location = /ru  { return 301 /ru/; }
location = /ru/ { root /var/www/eduapp/landing; try_files /ru/index.html =404; }
location = /tests     { return 301 /tests/; }
location = /tests/    { root /var/www/eduapp/landing; try_files /tests/index.html =404; }
location = /ru/tests  { return 301 /ru/tests/; }
location = /ru/tests/ { root /var/www/eduapp/landing; try_files /ru/tests/index.html =404; }
location /lp/   { root /var/www/eduapp/landing; expires 7d; }
location /      { root /var/www/eduapp/spa; try_files $uri $uri/ /index.html; }
```

Проверьте, что в Vue-приложении нет своего маршрута `/tests` — иначе выберите для каталога другой адрес (поле `path` страницы в `build.mjs`).

В самом Vue-приложении удалите старый маршрут лендинга `/`. Ссылки на главную из кабинета должны вести на `/` с полной загрузкой страницы (`<a href="/">`), а не через `router-link`.

## Эффекты в других местах (в том числе во Vue-кабинете)

```html
<link rel="stylesheet" href="/lp/fx.css">
<script src="/lp/fx.js" defer></script>

<div class="fx-galaxy" data-tilt="8">          <!-- живой фон + 3D-наклон + spotlight -->
  <span data-depth="30">выезжает при наклоне</span>
</div>
<a class="card" data-spot>…</a>                  <!-- только подсветка за курсором -->
<canvas data-starfield></canvas>                 <!-- мерцающие звёзды, внутри блока с position:relative -->
```

Во Vue 3 используйте директиву:

```js
app.directive("tilt", { mounted: (el) => window.EduAppFX.tilt(el) });
// <div class="fx-galaxy" v-tilt data-tilt="8">…</div>
```

Всё отключается при системной настройке «уменьшить движение». Тяжёлые `filter: blur` и `backdrop-filter` не используются, поэтому эффекты работают и на слабых телефонах.
